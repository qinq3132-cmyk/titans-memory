> **日期**：2026-11-27
> **Checkpoint**：`checkpoints_v7/ckpt_step_002000_final.pt`（v6 best 续训

> **输出**：`eval_v7_final/`（200 seqs × 6 长度，0 FAIL）

| variant | BPC | vs 自身干净 |

**对照 v6 ckpt（零训练 PTQ，实验 10/11）**：ch_max +4.04% / ch_mse +2.68%
——**全部数字与 v6 一致（差异 <0.05%）。2k 步骨干 QAT 无任何可测效果。**

其他观察：
- v7 干净基线 = 1.4039，与 v6 完全相同——QAT 训练没有损害也没有改变模型
- 全 4-bit 区域训练 loss 平坦（0.94–0.96，2186 步无下降趋势）——与部署
  评估的"无效果"互相印证

## 二、两个假设（当前数据不可区分）

- **假设 A（时间尺度）**：骨干适应需要数万步——v5 用 64k 步适应量化存储、
  v6 用 50k 步适应写噪声；本次 2.2k 步仅为 v5 的 3%，适应尚未发生。
  支持：训练 loss 平坦而非发散（模型稳定，只是还没学到）。
- **假设 B（不可训练）**：骨干 4-bit 的代价是量化粒度的信息擦除，训练
  无法消除（与 W_t 噪声性质不同——读出扰动可补偿，粒度擦除不可逆）。

## 三、区分方法与决策

唯一区分路径：**完整长度的 V7 训练（20–50k 步，4–12 小时）**。
- 若 50k 后部署代价下降 → 假设 A 成立，全 4-bit + QAT 路线可行
- 若 50k 后仍平坦 → 假设 B 成立，全 4-bit 的 +2.7%（ch_mse PTQ）就是
  训练不可再压缩的代价，接受它或用 8-bit 骨干（+0.73%）

## 四、当前部署结论（不受本次影响）

| 配置 | 代价 | 训练需求 |
|------|------|---------|
| NM 4-bit + 骨干 8-bit | +0.73% | 无 |
| 全 4-bit + ch_mse PTQ | +2.7% | 无 |
| 全 4-bit + 骨干 QAT | ≤+2.7%（待 50k 验证） | 20–50k 步 |

## 五、V7 训练机制备忘（供长训复用）

  STE，权重连续）；swap 在 DDP 前执行，参数键名不变，v6 ckpt 直接加载
- curriculum：bits 8→4 over warmup（v4 教训：step 0 全强度会崩——本次 2k
  冒烟全程稳定，curriculum 有效）

- 共享服务器鲁棒启动：`run_v7_smoke.sh`（动态选卡 + 双重检查 + 阶梯降级
  4→2→1 卡 + GRAD_ACCUM 保持等效 batch=32 + 自动重试）
